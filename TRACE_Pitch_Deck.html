Android On-Device AI Sensor Fusion Cryptography
01

The Problem

Deepfakes & Manipulation

Digital evidence is increasingly easy to fake. AI-generated audio and video make it impossible to trust raw media files.

Single Point of Failure

Existing security apps rely on just one sensor (only video or only audio). They lack environmental context and are prone to false positives.

No Chain of Custody

Once a video is recorded on a phone, there's no cryptographic proof that it hasn't been edited or trimmed before being presented.

02

The Solution: TRACE

TRACE turns any Android phone into an autonomous, tamper-proof evidence gathering platform. The mobile phone isn't just a viewer—it is the main intelligence hub.

  • Continuous Monitoring: Simultaneously watches (Camera), listens (Mic), and feels (Accelerometer) the environment.
  • Sensor Fusion: Cross-references multiple sensors in real-time. If the camera sees an impact but the accelerometer feels nothing, TRACE flags it as unconfirmed.
  • Cryptographic Proof: Every event is permanently sealed in a SHA-256 hash chain. If one frame or log is deleted, the entire chain invalidates.
  • 100% Offline: No cloud processing. Complete privacy using on-device ML.
03

Architecture & Data Flow

1. OBSERVATION: Sensors detect a spike (e.g., motion jerk > 3.0, mic amp > 1500).

2. EXTRACTION: Mapped to categories ('impact', 'alarm', 'object_moves').

3. FUSION ENGINE: Checks other sensors in a 2s window. ≥2 strong sensors = CONFIRMED.

4. HASH CHAIN: SHA-256 hash generated incorporating the previous event's hash.

5. STORAGE: Saved to Room DB. Live .amr audio clip securely copied.
04

Key Features

🎥 Smart Video Import

Upload random video clips. TRACE sorts them chronologically by metadata, analyzes frames every 5s using ML Kit Image Labeling, and integrates them into the timeline.

💬 NLP Query Engine

Ask plain-English questions like "what happened before the alarm?" TRACE searches the local database and returns contextual answers without needing an LLM.

🛡️ Honest AI

We don't blindly trust AI. TRACE explicitly separates CONFIRMED (multi-sensor agreement) from UNCONFIRMED (single-sensor) events.

🎨 Cyberpunk UI

A beautifully designed, immersive HUD. Features live camera backgrounds, chronological timelines, and color-coded confidence bars.

05

Technical Stack

  • Language: 100% Kotlin
  • Concurrency: Kotlin Coroutines & Flow for non-blocking sensor polling
  • Local Database: Android Room (SQLite)
  • Machine Learning: Google ML Kit (Object Detection & Image Labeling)
  • Hardware APIs: CameraX, SensorManager, MediaRecorder
  • UI: XML Layouts + Material Components
